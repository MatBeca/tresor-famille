# Le trésor d'Erin et Ava

Application familiale d'argent de poche : paie hebdomadaire en pièces, bocal qui se remplit, bonus des parents, bourse de la semaine au dé, projection jusqu'à 18 ans, argent reçu, virements vers le Livret A et mode enfant verrouillé par code.

- `index.html` : l'application (PWA installable)
- `config.js` : configuration Firebase (identifiants publics)
- `firestore.rules` : règles de sécurité à coller dans la console Firebase
- `sw.js`, `manifest.webmanifest`, `icons/` : installation sur Android et démarrage hors ligne

Installation sur Android : ouvrir l'adresse GitHub Pages dans Chrome, menu ⋮, « Installer l'application ».
